Circular Queue Visualizer
Student : Rathod Vraj (Roll No 26MCA050)
Faculty : Assistant Professor Nirav Patel

HOW TO RUN THE VISUALIZER
Keep index.html, style.css and script.js in the same folder and open index.html in any browser.
No installation or internet is needed.

HOW TO RUN THE C PROGRAMS
gcc circularqueue_array.c -o array
gcc circularqueue_singly_ll.c -o singly
gcc circularqueue_doubly_ll.c -o doubly

FILES
index.html, style.css, script.js     - web visualizer (array, singly and doubly linked list modes)
circularqueue_array.c                - circular queue using an array
circularqueue_singly_ll.c            - circular queue using a singly linked list
circularqueue_doubly_ll.c            - circular queue using a doubly linked list
26MCA050_Circular_Queue_Visualizer.pptx - presentation (16 slides, with speaker notes)
26MCA050_Circular_Queue_Vizualization.docx - project report (Word)
26MCA050_Circular_Queue_Visualizer.pdf  - project report (PDF)

NOTE
The visualizer allows a capacity of 3 to 15 so that the ring can be drawn clearly.
The C array program uses SIZE 50.
